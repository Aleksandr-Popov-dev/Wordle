# 🟩 Wordle Clone

> Минималистичная копия популярной игры Wordle на SwiftUI.  
> Угадай слово за 6 попыток — простая механика, приятный дизайн и чистая архитектура.

---

## 🎯 Особенности

- **Случайное слово** из встроенного словаря (можно расширять)
- **Цветовая индикация**: зелёный — буква на месте, жёлтый — есть в слове, серый — нет
- **Валидация ввода**: только реальные слова (проверка по словарю)
- **Клавиатура**: кастомная (в стиле оригинального Wordle)
- **Статистика**: смотри статистику по сыгранным играм

---

## 🧩 Архитектура проекта

Проект построен на **Clean Architecture** и **MVVM**, чтобы отделить логику игры от отображения

## 🚀 Как запустить

1. Склонируй репозиторий:
   git clone https://github.com/твой-ник/wordle-clone.git
2. Открой проект в Xcode (файл .xcodeproj или .xcworkspace)
3. Выбери симулятор iPhone (или свой девайс)
4. Нажми Run
